## 🔭 Projects

### 🧠 [Neuro-symbolic AI for legal document analysis](https://github.com/crxstqn/degree-project) · *Bachelor's thesis*
Pipeline that extracts articles from university Statutes and Regulations (PDF), matches related articles, uses an LLM to translate them into logical facts, and detects contradictions (negation, modal, numerical, structural) with Answer Set Programming.
`Python` `LLMs (gpt-oss via Groq)` `Answer Set Programming` `clingo` `pdfplumber`

### ✈️ [Roadies](https://github.com/crxstqn/roadies) · *Team project, Enterprise Applications*
Platform for organizing, booking and reviewing group trips, with real-time chat between organizers and travellers. Microservice backend (Spring Boot, Eureka, API gateway) with **Keycloak OAuth2/JWT** role-based authentication, RabbitMQ messaging, Stripe payments, and a native Android app.
`Java 21` `Spring Boot` `Kotlin` `Keycloak` `PostgreSQL` `RabbitMQ` `Docker`

### 🏥 [HealthConnect](https://github.com/crxstqn/healthconnect) · *Team project, Web Applications*
Web platform for medical bookings and digital health records, with three roles (patient, doctor, admin), admin approval of doctor accounts, internal chat and charts of vital parameters.
`Angular` `TypeScript` `Spring Boot` `PostgreSQL`

### 🏆 [EasyTournament](https://github.com/crxstqn/easytournament) · *Software Engineering*
Desktop app to manage tournaments (round-robin and knockout), teams and results, built with the MVC pattern and **BCrypt** password hashing.
`Java` `JavaFX` `SQLite` `Maven`

### 🎓 [EasySplit](https://github.com/crxstqn/easysplit) · *User Interface Design*
Desktop app for university students to track grades, weighted average and expected graduation score, with charts and PDF export.
`Java` `JavaFX` `SQLite`
